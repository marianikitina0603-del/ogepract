# Технический аудит практикума ОГЭ

Исходная версия — коммит [72f298e](https://github.com/marianikitina0603-del/ogepract/commit/72f298e9a467eaf82ae08ab446037fe94fb1b485). Объём аудита — каталог, общий интерфейс и хранение, пять интерактивных моделей урока «Шины», печать и отправка на доску. «Дороги» входят в проверку обратной совместимости.

## Исходное состояние и решения

| Требование | Исходное состояние | Изменение или граница проверки |
|---|---|---|
| Каталог и вход в урок | Два материала, 21 тематический раздел. Уроки открывались на всю страницу. Старый диалог с iframe оставался в исходнике без входа | Каталог открывает урок обычной ссылкой. Повреждённый адрес раздела обрабатывается безопасно |
| Подключаемый шаблон | Модели уже были отделены от общего интерфейса. Ядро подставляло фиксированные номера вариантов и подразумевало одинаковое число задач | Выбор комплектов, проверка конфигурации и работа с ключами вынесены из ядра. Дефолты совместимы с текущими уроками |
| Проверка и обратная связь | Конечный ответ, три уровня подсказки, пошаговое решение, общие ошибки. Подсказка по промежуточным расчётам открывала готовое вычисление | Добавлены независимые проверки промежуточных шагов, признаки помощи и разбор ошибок по введённому результату |
| Контроль и итоги | Ответы оценивались при сохранении. Итоговый слайд сразу сообщал результат и позволял угадывать через повторные проверки | Контроль завершается явным действием. После завершения ответы фиксируются, на итогах видны верные, ошибочные и пропущенные задания |
| Теория | Общие карточки и контекст задачи были частью ядра. Популярные ошибки в одном абзаце | Отдельный модуль теории. У «Шин» добавлены план решения, разбор маркировки на модели и пример проверки результата |
| Вид и управление окнами | Перемещение и размер через мышь. Края окон могли уйти за видимую область. На узком экране сохранялась большая ширина панели | Управление размером и положением ограничено размерами экрана. В разделённом режиме тетрадь прокручивается независимо |
| Рисование | Перо, маркер и ластик уже были. Canvas многократно перерисовывался за кадр. Отмена очистки по одному штриху, положение отменённых штрихов после расширения тетради менялось | Перерисовка по кадрам. Очистка отменяется целиком. Расширение тетради сохраняет положение видимых и отменённых штрихов |
| Клавиатура и навигация | Физические клавиши, экранные символы и дробное превью. Экранная клавиатура слишком широка для краткого числового ответа | Числовая и расширенная раскладки, нормализация десятичных дробей, проверка перемещения по слайдам и ввода без конфликтов |
| Автосохранение и JSON | Хранение локальное, импорт с проверкой. Один повреждённый блок мог обнулить локальный прогресс | Локальное восстановление сохраняет валидную часть. Импорт проверяет весь файл до замены. Старые ключи и форматы сохранены |
| Тетрадь, PNG и печать | Три типа бумаги, масштаб, PNG, ZIP, A4/A5. Разрез длинной записи использовал фиксированное число пикселей | Для печати изолированы условие и рукопись. Размер разбиения вычисляется по области листа с учётом высоты условия. Печать через браузер сохраняет PDF |
| Доска | Работает перенос условия, слайда и тетради между окнами. Снимки доступны в локальном показе | Общий модуль сохранён. Реальная совместная работа на разных устройствах проверяется отдельно |
| Числа и модели «Шин» | Пять заданий демоверсии и 15 аналогов из сборника. Пропорции в пределах исходных вариантов корректны. На крайних значениях профиля колесо могло выходить за границу чертежа | Проверяются геометрические границы, масштаб двух изображений, разность радиусов и кинематика качения |
| Дополнительные инструменты | Геометрические инструменты и игровые сценарии относятся к пожеланиям или к другим типам уроков | Фигуры, линейка, циркуль, транспортир и текстовые заметки остаются расширениями. Содержание по остальным номерам не создаётся в рамках аудита |

Источник заданий — А. Д. Остромогильский, «Открытый банк задач ФИПИ. ОГЭ по математике», обновление от 28.08.2026. Для «Шин» использованы стр. 9–11 и 176–182, контрольные ответы сверяются со стр. 1149.

## Воспроизведение проверок

```sh
node --test tests/*.test.mjs
python3 -m http.server 8000
```

Для ручной проверки открыть урок через каталог. Пройти 5 моделей, проверить каждый режим и ошибочный ответ, ввести дробь через экранную клавиатуру, сделать по одному штриху на слайде и в тетради, закрыть окна и перезагрузить. Сравнить сохранённые значения и пометки. Для экспорта проверить PNG с чертежом, ZIP всей тетради, перенос на доску и предпросмотр печати длинной записи в A4/A5. Отдельно проверить узкий экран и физический стилус или планшет.

## Результаты проверки 25 ноября 2026 г.

- 11 автотестов прошли. Сверены 20 ответов, допустимый ввод, учёт помощи, завершение контроля, совместимость со старыми ключами, валидация отчёта, математические модели, разбиение печати и структура ZIP.
- На GitHub Pages проверены переход из каталога, выбор разрешённой шины, изменение размеров по ползункам, три части диаметра, наложение контуров, счётчики пути, финиш и сброс анимации. Проверены четыре режима, дробь с экранной клавиатуры, обратная связь при типичной ошибке, проверка промежуточного шага, сохранение ответа, подсказки и раскрытого шага при перезагрузке.
- В браузере проверены открытие, сворачивание, изменение размера и разворачивание теории, режим рядом с задачей, рисование мышью, отмена и возврат штриха. Проверено, что отменённый штрих можно вернуть после увеличения листа.
- Подтверждено скачивание PNG слайда, PNG страницы, ZIP тетради и отчёта JSON. Проверена подготовка многостраничной печати A4 и A5. Фактическая распечатка устройством в аудит не входит.
- Импорт валидного и отклонение повреждённого отчёта проверены в автотесте. Сценарий с файловым диалогом браузера прервался по тайм-ауту среды.
- Физический стилус, сенсорные жесты, мобильные браузеры и совместный режим на разных устройствах требуют отдельных проверок.
