# Общие модули

- `lesson-core.js` связывает задания с интерфейсом, режимами и прогрессом.
- `storage.js` проверяет структуру сохранённого состояния и отчётов.
- `annotation.js` управляет слоями рукописных записей и историей действий.
- `notebook.js` управляет страницами тетради, настройками бумаги и экспортом.
- `panels.js` управляет плавающими окнами тетради, теории и навигации.
- `math-keyboard.js` добавляет экранный ввод и проверяет формат числовых ответов.
- `export.js` сохраняет PNG, JSON и готовит материалы к печати.
- `lesson-ui.css` содержит стили урока и печати.

Каждый урок вызывает `startLesson(config)`. Конфигурация задаёт устойчивый ключ сохранения, название, вступление, HTML теории и наборы задач. Каждый набор содержит подпись и массив задач в одном порядке. У задачи указываются условие, ответ, подсказки, шаги решения и, при наличии, функция `mount(element, options)` для её модели. В режимах самостоятельной и контрольной работы функция получает `reveal: false`.

Весь HTML условий, схем, теории и пояснений задаёт сам урок. Тетрадь берёт заголовок, условие и данные задачи из её конфигурации. Учебный ответ и история ввода из тетради исключены. Ключи сохранения задания входят в формат JSON и нужны для совместимости между выпусками.
