# Общие модули

- `lesson-config.js` задаёт режимы, проверяет комплекты и формирует ключи прогресса.
- `assessment.js` проверяет ответы и промежуточные шаги, учитывает помощь и завершает контроль.
- `theory.js` выводит общую и контекстную теорию и при необходимости включает модель.
- `interactive-math.js` содержит расчёт масштаба увеличенного фрагмента и управление анимацией.
- `notebook-print.js` делит тетрадь на печатные листы A4/A5.
- `lesson-core.js` связывает задания с интерфейсом, режимами и прогрессом.
- `storage.js` проверяет структуру сохранённого состояния и отчётов.
- `annotation.js` управляет слоями рукописных записей и историей действий.
- `notebook.js` управляет страницами тетради, настройками бумаги и экспортом.
- `panels.js` управляет плавающими окнами тетради, теории и навигации.
- `math-keyboard.js` добавляет экранный ввод и проверяет формат числовых ответов.
- `board-bridge.js` передаёт снимки на математическую доску и ждёт подтверждения вставки.
- `export.js` сохраняет PNG, JSON и готовит материалы к печати.
- `lesson-ui.css` содержит стили урока и печати.

Каждый урок вызывает `startLesson(config)`. Конфигурация задаёт устойчивый ключ сохранения, название, вступление, HTML теории и наборы задач. Каждый набор содержит подпись и массив задач в одном порядке. У задачи указываются условие, ответ, подсказки, шаги решения и, при наличии, функция `mount(element, options)` для её модели. В режимах самостоятельной и контрольной работы функция получает `reveal: false`. Если модель выводит готовое вычисление в учебном режиме, она вызывает `options.onReveal()`.

### Контракт конфигурации

| Поле | Назначение |
|---|---|
| `key`, `slug` | Устойчивый ключ хранилища и префикс имени экспортируемого файла |
| `title`, `shortTitle`, `intro`, `source` | Заголовки, вступление и источник урока |
| `section`, `catalogUrl` | Подпись группы и путь возврата. Для разделов от №6 указывайте их явно |
| `theoryTitle`, `theory`, `mountTheory` | Заголовок, HTML и необязательная интерактивная модель теории |
| `sets` | Массив комплектов `{ label, tasks }`. Комплекты имеют одинаковое число позиций. Один комплект разрешён |
| `modeSets` | Необязательные индексы комплектов по режимам `study`, `practice`, `independent`, `test` |
| Задача | `title`, `source`, `statement`, числовой `answer` или функция `check`, необязательные `context`, `mount`, `hints`, `steps`, `checkpoints` и `mistakes` |
| `id` | Устойчивая идентификация позиции из основного комплекта для новых уроков. В опубликованных уроках с номерными ключами сохраняйте прежний порядок задач |
| `keyboard` | Значение `full` включает знаки для выражений. Собственный метод `check` задаёт проверку такого ответа |

Урок состоит из HTML-контейнера, подключения `lesson-ui.css`, собственных стилей при необходимости и вызова `startLesson(config)`. Формулы в HTML можно окружить знаками доллара. Снимки на доску передаются как изображения.

Весь HTML условий, схем, теории и пояснений задаёт сам урок. Тетрадь берёт заголовок, условие и данные задачи из её конфигурации. Учебный ответ и история ввода из тетради исключены. Ключи сохранения задания входят в формат JSON и нужны для совместимости между выпусками.
