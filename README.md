# Практикум ОГЭ

Главная страница — index.html. Каталог — catalog.js. Папки tasks/1-5, tasks/6 … tasks/25 предназначены для самостоятельных HTML-уроков и их ресурсов.

## Добавление материала
1. Поместите HTML и связанные ресурсы в папку соответствующего номера, например tasks/1-5/roads/index.html.
2. Добавьте объект в массив window.OGE_MATERIALS в catalog.js:

```js
{topic: '1-5', type: 'lesson', title: 'Дороги', description: 'Интерактивный урок', path: 'tasks/1-5/roads/index.html'}
```

Типы: lesson, theory, trainer, practice, game, test. Путь должен быть относительным к корню сайта. Пустые разделы не содержат фиктивных ссылок. Общие инструменты находятся в `shared/`.

## Публикация
Settings → Pages → Deploy from a branch → main → / (root).

## Аудит и проверка

[Технический аудит](docs/technical-audit.md) фиксирует требования, найденные дефекты, способы проверки и границы покрытия. Команда `npm test` проверяет математику, хранилище и контракт общего шаблона. Для запуска тестов нужен Node.js 20 или новее, сторонние пакеты не требуются.

Новые разделы добавляются после проверки эталонного урока на целевых устройствах.

## Эталонный урок «Шины»

Урок использует общие модули из `shared/`. Локальные файлы `lesson.js` и `wheels.js` содержат задачи, формулы и модели колёс. Точка входа `start.js` передаёт конфигурацию в общий шаблон. Три комплекта аналогов взяты из сборника А. Д. Остромогильского от 28.08.2026, стр. 176–182. Задания демоверсии 1.3–5.3 приведены на стр. 9–11.

Порядок работы при добавлении следующего урока

1. Сверить задания и числовые данные со сборником. Записать номера задач, страницы и отметки источника.
2. Заполнить конфигурацию по контракту в `shared/README.md`. Использовать отдельный ключ прогресса для каждого урока.
3. Встроить модели в слайды соответствующих задач. Численные расчёты и решения открываются только по действию ученика в учебных режимах.
4. Проверить ответы, учебные модели, ввод, рисование, восстановление прогресса, тетрадь, экспорт и отображение на узких экранах.
5. Добавить урок в каталог. При изменении учебного HTML, каталога или их стилей обновить параметр версии у изменившихся ресурсов.

Печать слайда и тетради позволяет выбрать A4 или A5. PDF сохраняется через диалог печати браузера. Общие модули работают в браузере и сохраняют прогресс локально. Кнопка «На доску» передаёт снимок выбранного материала в раздел «Запись решения» математической доски. Передача идёт напрямую между окнами браузера. Открытое из урока окно можно использовать для следующих отправок и для режима показа.

Урок «Дороги» использует общий интерфейс и собственные модели плана и поездки в `tasks/1-5/roads/`. Он охватывает задачи 1.1–5.1 со стр. 5–6 и аналоги со стр. 129–134. В прототипе 1.2 на стр. 7 расстояние Антоновка — Доломино указано как 12 км. Ответ к задаче 2.2 на стр. 1148 подразумевает 4 км. Этот прототип пока не включён.
